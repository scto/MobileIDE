# LSP Plugins Repository

This directory contains all offline-installable plugin ZIP packages and catalog metadata for MobileIDE Plugin Store.

## Node-Based LSP Plugins
The following 6 LSP plugins require Node.js (`runtime-node`) in the sandbox environment:
- **CSS Language Support** (`com.scto.mobile.ide.css_lsp`): CSS, SCSS, LESS language server powered by vscode-css-language-server (requires nodejs).
- **Emmet Language Support** (`com.scto.mobile.ide.emmet_lsp`): Emmet completion language server powered by emmet-ls (requires nodejs).
- **ESLint Support** (`com.scto.mobile.ide.eslint_lsp`): JavaScript/TypeScript linter powered by vscode-eslint-language-server (requires nodejs).
- **HTML Language Support** (`com.scto.mobile.ide.html_lsp`): HTML language server powered by vscode-html-language-server (requires nodejs).
- **Markdown Language Support** (`com.scto.mobile.ide.markdown_lsp`): Markdown language server powered by marksman/vscode-markdown-language-server (requires nodejs).
- **TypeScript & JavaScript Language Support** (`com.scto.mobile.ide.typescript_lsp`): TypeScript and JavaScript language server powered by typescript-language-server (requires nodejs).
